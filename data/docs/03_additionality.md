# Additionality in Carbon Projects

Additionality ensures that carbon credits represent real climate benefits.

A project is additional if it would not occur without carbon finance incentives.

## Common Tests of Additionality

### Financial Additionality
The project is not economically viable without carbon revenue.

### Regulatory Additionality
The activity is not legally required.

### Common Practice Test
The activity is not already widespread in the region or sector.

## Risks to Additionality

- Overstated baselines
- Existing profitable activities claiming credits
- Policies already mandating the activity

Additionality is central to carbon credit credibility.
