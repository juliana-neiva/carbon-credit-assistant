# Baseline Determination

The baseline represents emissions that would occur without the project.

It is essential for calculating emission reductions:

Emission Reductions = Baseline Emissions − Project Emissions

## Baseline Approaches

- Historical emissions
- Performance benchmarks
- Modeled counterfactual scenarios

## Baseline Risks

- Inflated assumptions
- Outdated data
- Ignoring trends or policies

An unrealistic baseline leads to over-crediting.
